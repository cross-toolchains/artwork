## Usage Guidelines

- Keep the SVG proportions intact (1:1 aspect ratio, `viewBox="0 0 64 64"`).
- Prefer `logo/logo.svg` on dark surfaces (`#0b0e14` or darker) and `logo/logo-light.svg` on pure white backgrounds.
- You are free to use these assets when referencing, documenting, or integrating with `cross-toolchains` (`xsysroot`, `xcompiler`, `xforge`, `xsign`, `xbundle`, `xross`).
